# 🔮 Taro — Daily Tarot Task Planner

Mobile app that turns your daily to-do into a magical tarot ritual.

Each morning the cards greet you with **"Your task for today"**. Choose one of three cards — the others burn away in golden sparks, and your card flips to reveal a task with a thematic quote. You have **12 hours** to complete it. Your streak grows. Stats and history unfold like a deck of memories.

Built with **Expo + React Native + TypeScript**.

## Стек

- Expo SDK 54
- React Native 0.81 + React 19
- TypeScript
- `react-native-reanimated` for 60 FPS animations
- `react-native-svg` for ornate card art
- `expo-haptics` for tactile feedback
- `@react-native-async-storage/async-storage` for local persistence
- `zustand` for state management
- Groq API (free tier) for AI task generation

## Запуск

```bash
npm install
npx expo start
```

Откройте Expo Go на телефоне и просканируйте QR-код.
